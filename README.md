# Financial & Sales Performance Dashboard

## Project Overview
This project analyzes an e-commerce sales dataset using Power BI to evaluate financial performance across products, regions, and time. The dashboard was designed to help business users monitor key performance indicators (KPIs), identify sales trends, and compare product performance through interactive visualizations

## Business Objective
Develop an interactive dashboard that enables stakeholders to monitor revenue, profit, sales performance, and regional trends to support data-driven business decisions.

## Dashboard Features
- KPI Cards for Total Revenue, Total Profit, Profit Margin, and Quantity Sold

- Regional Sales Comparison
- Interactive Filters (Region, Category, Year)
- Profit vs. Sales Analysis
